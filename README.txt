ProCam - build steps
1. Install Android Studio (free): developer.android.com/studio
2. File > Open > select this ProCam folder. Let Gradle sync finish (needs internet).
3. Build > Build Bundle(s)/APK(s) > Build APK(s). Click "locate" when done.
   APK path: app/build/outputs/apk/debug/app-debug.apk
4. Copy the APK to your Tecno Spark 30, tap it, allow "install unknown apps".
